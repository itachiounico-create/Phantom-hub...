
# PHANTOM

Projeto modular de interface para Roblox.

## Versão
0.1.0

## Estrutura
- `Main.lua` — inicialização
- `Modules/Config.lua` — configurações
- `Modules/PhantomUI.lua` — interface
- `Modules/Components.lua` — componentes reutilizáveis
- `Pages/Home.lua` — página principal
- `Pages/Settings.lua` — configurações do menu
- `Assets/` — recursos visuais

## Objetivo
Desenvolver uma interface organizada,
modular e adaptada para dispositivos móveis.

## Status
Em desenvolvimento.
